# UI Pass 2 — No Overlaps, Exit Buttons, Larger & Clearer

## Goal
Eliminate every overlapping HUD/menu element at the target portrait resolution (1080×1920), add explicit exit affordances, and scale up type/touch targets one full step for readability.

## Audit findings (verified against current scenes)
1. **CombatCard** (x 330–750, y 20–118) collides with **MetaRow** chips/buttons (x 520–1060, y 16–150) whenever combat starts.
2. **BossHealthBar** (x 210–870, y 20–112) collides with MetaRow even worse.
3. **LevelToast** (y 140–220) clips MetaRow's action-button row (~y 116–150).
4. **FieldNote** uses `anchors_preset = 3` (all anchors 1.0) with `offset_left = +20` → left edge (1100) > right edge (1060): inverted rect, broken render.
5. Landing page: **VersionChip** sits in the same bottom band as **FooterHint** (near-collision once text grows).
6. Small touch targets: MetaRow buttons (~34 px tall, font 9), dodge/jump 88 px, cooldown labels font 9, chips font 12.
