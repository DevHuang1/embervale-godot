# Boss Roster V2 source family

`build_boss_roster_v2.py` is the editable Blender source builder for the eight
canonical bosses. It uses the shared `assets/textures/bosses_v2/` atlas and ORM
texture, emits the common articulated armature/socket contract, and exports
three LODs plus authored action prefixes.

Run from the repository root on a Blender-capable workstation:

```sh
blender --background --python tools/blender/build_boss_roster_v2.py
```

The checked-in GLBs are generated by the same contract-preserving fallback when
Blender is unavailable in headless CI. The fallback is not a replacement for
the editable Blender source; it keeps runtime validation reproducible.
