# Terrain V2 Texture Set

The versioned `grass_v2`, `sand_v2`, `moss_v2`, and `mud_v2` folders contain
clean project-owned albedo textures generated for Embervale's terrain pass.
They are square, tile-oriented references for the dark-fantasy PBR style and
are bound by `TerrainRelief` when present. Existing normal and roughness maps
are reused until authored maps are produced for each surface.

Provenance: generated in-session with the Codex image generation tool from
original descriptive prompts; no third-party artwork or watermark is shipped.
